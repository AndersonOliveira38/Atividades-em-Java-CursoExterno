# ☕ Exercícios de Java - Curso Externo

Este repositório reúne os exercícios práticos de Java desenvolvidos durante um curso externo. O objetivo principal é fixar a lógica de programação e os fundamentos iniciais da linguagem.

## 🎯 Conceitos Praticados
- Sintaxe básica e estrutura de programas.
- **Estruturas condicionais** (`if`, `else`, `else if`).
- Operadores lógicos e relacionais.
- Entrada e saída de dados no console (`Scanner` e `System.out`).

## 📂 Sobre os Exercícios
Os códigos focam na tomada de decisão, onde o programa avalia condições e executa blocos de instruções diferentes com base nos resultados (verdadeiro ou falso) utilizando `if` e `else`.

## ⚙️ Como Executar

Certifique-se de ter o **JDK** (Java Development Kit) instalado. No terminal, navegue até a pasta do exercício e utilize os comandos:

```bash
# 1. Compilar o código
javac NomeDoExercicio.java

# 2. Executar o programa
java NomeDoExercicio
